# Changelog

- v1: decks, study (FSRS), cloze, add/edit, .apkg import/export, browse, deck options, stats, logins
- Card actions: suspend/unsuspend, bury card/note, 7 flags, mark, reset to new, set due date (study screen menu + Anki keys, edit page Cards panel); Browse shows flag/suspended/buried/marked
- Card info page (`/card/{id}/info`): engine card stats (dates, interval, due, reviews, lapses, times, ease or FSRS stability/difficulty/retrievability) and full review history; linked from study (More menu, I key), edit page and Browse
- Browse upgrade: cards/notes mode, engine-rendered columns (due, interval, ease, reviews, lapses, …) with a column chooser, sort by clicking a header, checkboxes + "all in search" with bulk change deck, add/remove tags, suspend/unsuspend, flag, set due date, reset, reposition new cards, delete; find and replace in fields or tags
- Study screen parity: Again cards come back in the session (with a "next learning card in N minutes" wait screen for long steps); Edit/Card info return to the same card and side with the timer kept; type-in answers ({{type:Field}}, cloze, nc:) compared by the engine; Anki-style audio play buttons, autoplay and replay (R) honouring deck options, TTS via the browser, inline video; "Card was a leech" notice
- Deck options parity (`/deck/{id}/options`): all main Anki options (limits incl. this-deck-only, learning/relearning steps, intervals, insertion/gather/sort/mix/review order, burying, leeches, audio, SM-2 ease settings, FSRS toggle/retention/parameters) saved through the engine's options call; presets add/clone/rename/delete/choose; save to all subdecks; FSRS Optimize button using the engine's optimizer. Deck options routes moved to `flashcards/deck_options.py`
- Custom study (`/deck/{id}/custom`, `flashcards/custom_study.py`): Anki's dialog via the engine's `custom_study` call — raise/lower today's new or review limit, review forgotten cards, review ahead, preview new cards, study by card state with tag include/exclude; builds the "Custom Study Session" filtered deck and opens it. Filtered deck overview gets Rebuild/Empty; finished decks link to custom study
- Filtered decks (`/filtered/new`, `/deck/{id}/filtered`, `flashcards/filtered_decks.py`): Anki's filtered deck dialog via the engine's `get_or_create_filtered_deck`/`add_or_update_filtered_deck` — name, search, limit, order (all 11 of Anki's orders), optional second filter, reschedule on/off with Again/Hard/Good preview delays, "create even if empty"; create from the deck list or from a Browse search; Options/Rebuild/Empty on the filtered deck overview
- Note type manager (`/notetypes`, `flashcards/notetypes.py`, linked from Settings, Add and Edit): list with note counts; add from Anki's stock types (Basic, and reversed, optional reversed, type-in, Cloze, Image Occlusion) or clone; rename; delete. Fields: add, rename (templates follow), reorder, delete, sort field, font/size, description, RTL, sticky and other field options. Cards: front/back/styling editor with live preview rendered by the engine (a real note of that type, or a blank one), add/rename/reorder/delete card types, per-cloze preview. Change note type of notes (from Browse's Action menu or the Edit page) with field and card mapping via the engine
- Rich editor for Add/Edit (`flashcards/editor.py`): toolbar with bold/italic/underline, sub/superscript, text and highlight colour, bullet/numbered lists, remove formatting; cloze buttons and Anki's keys (Ctrl+Shift+C new number, Ctrl+Shift+Alt+C same number); MathJax inline/block (Ctrl+M M / Ctrl+M E) rendered with MathJax 3 in cards and previews; paste/drop/attach pictures, audio and video; record audio; per-field HTML editor (Ctrl+Shift+X) and the note type's field options (font, size, RTL, HTML editor by default, collapsed, description); sticky fields (📌) and tags kept after Add; live duplicate warning with "Show Duplicates" and cloze warnings from the engine's field check; a missing-cloze note asks "Add anyway"; refused adds keep the input; Preview of every card the note would make; Ctrl+Enter saves
- Image occlusion (`/io/new`, `/io/{nid}`, `flashcards/image_occlusion.py`): make Anki Image Occlusion notes from a chosen, dropped or pasted picture; draw rectangles and ellipses (move, resize, delete, duplicate, group/ungroup, undo/redo, keyboard shortcuts, touch friendly); "Hide all, guess one" or "Hide one, guess one"; header, back extra, tags and deck. Uses the engine's own image occlusion calls, so notes match desktop Anki. Edit opens the mask editor and keeps card numbers; polygons, text and pixel-position masks from desktop Anki load and save. Cards draw their masks with a port of Anki's `imageOcclusion.setup()`, including Toggle Masks. Add switches to the mask editor for these note types
- Import/export (`/import`, `/export`, `flashcards/import_export.py`): .apkg import with Anki's options (learning progress, deck presets, merge note types, update notes/note types) and a per-note import log; text import (CSV/TSV/TXT) via the engine's `get_csv_metadata`/`import_csv` with separator, HTML, note type, deck, field mapping, tags column, extra tags, existing-note handling and match scope, plus a preview; .colpkg import that replaces the collection after a confirm and an automatic backup; export as .colpkg, .apkg (all decks, one deck or a Browse search) and notes/cards in plain text with Anki's include options. Links from the deck overview and Browse
- Media (`/check-media`, `flashcards/media.py`, linked from Settings): Anki's Check Media via the engine's `check_media` — missing and unused files (with thumbnails), Tag Missing (`missing-media`) and Browse link for affected notes, Delete Unused (all or ticked) to the media trash, Restore Deleted, Empty Trash, full engine report. `/media/` now sends correct audio/video/image types with Range support for Safari, finds NFD-encoded names, and sandboxes HTML/SVG files
- Statistics (`/stats`, `flashcards/stats.py`): Anki's graphs from the engine's `graphs` call — Today, Future Due (backlog), Calendar heatmap with year navigation, Reviews (count/time), Card Counts pie (separate suspended/buried), Review Intervals, FSRS Difficulty/Stability/Retrievability or SM-2 Ease, Hourly Breakdown, Answer Buttons, Added, Retention table; deck/collection/search scope and 1 month/3 months/1 year/all range; tap a bar for details and a Browse link; Stats button on the deck overview
